# GearDrawer

Adobe Illustrator 用のインボリュート平歯車作図スクリプト（ExtendScript / JSX）。
レーザーカッターやCNC切削による実動パーツの切り出しに特化し、噛み合う2つの歯車を正確な幾何学配置および回転位相で自動描画します。

## 主な機能 (v0.2.0)

- **厳密なインボリュート曲線**: JIS B 1701準拠の歯形幾何計算。
- **歯元隅肉曲線（創成トロコイド包絡線）**: ホブ・ラック工具の刃先丸み（\(r_c = 0.38m\)）による厳密なフィレットを創成計算。歯元の応力集中を緩和し、小歯数におけるアンダーカット（切下げ・えぐり込み）形状も完全再現。
- **噛み合い自動配置**: 中心間距離 \(a = \frac{m(z_1 + z_2)}{2}\) およびピッチ点での噛み合い回転位相を自動計算。
- **レーザー加工補正**:
  - バックラッシ（歯厚の遊び）設定
  - カーフ幅（ビーム径切代）補正
- **動的切下げ（アンダーカット）判定**: 圧力角に応じた限界歯数 \(z_{min} = \frac{2}{\sin^2 \alpha}\) をリアルタイム算出し警告。
- **軸穴・ガイド線の同時描画**: シャフト穴、ピッチ円ガイド（点線）、中心クロスヘア、諸元テキストラベルの出力。
- **高信頼性・環境非依存**: ソースコードの純ASCII（Unicodeエスケープ）化およびBOM付きUTF-8により、日本語Illustrator環境での文字化けエラーを完全防止。

## 使い方

1. Adobe Illustrator を起動し、新規ドキュメントを作成します（単位はミリメートル推奨）。
2. メニューの **ファイル > スクリプト > その他のスクリプト...** を選択します。
3. `GearDrawer.jsx` を選択して実行します。
4. ダイアログ上でモジュール、圧力角、歯数、軸穴径などを入力し、「歯車を描画」をクリックします。
