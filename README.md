# GearDrawer

Adobe Illustrator 上で動作する、レーザーカッター・CNC切削・3Dプリント向けの実動インボリュート歯車自動作図スクリプト (ExtendScript / JSX)。

JIS B 1701-1 / JIS B 0003 / JIS B 1301 に準拠した厳密な歯形幾何計算と 3 次ベジェ曲線フィッティングにより、単体歯車から多段分岐輪列、遊星・不思議遊星・間欠歯車機構までを一貫して自動作図する。

## 主な機能

- 対応歯車・機構形式
  - 外歯平歯車 (転位・歯先短縮・アンダーカット創成・歯先丸み対応)
  - 内歯車 (リム構造・内接4大干渉バリデーション対応)
  - 直線ラック (背面厚み基準切替対応)
  - 多段・分岐輪列 (同軸積層、任意配置角での共役噛み合い位相合わせ、正面噛み合い率検証)
  - 標準遊星歯車機構 (2K-H型 : 目標減速比探索・等配/隣接干渉検証・キャリア生成)
  - 不思議遊星歯車機構 (3K型差動 : 堀理論による全歯車正転位配分・Willis厳密減速比探索)
  - 間欠歯車機構 (単層型・2層積層Genevaロック板型・停止ロック姿勢整合)
- 幾何精度とベジェ最適化
  - 創成トロコイド包絡線による歯元隅肉曲線および切下げ (アンダーカット) 再現
  - 3次ベジェ曲線近似 (推奨 9〜11 点/歯、最小 7 点/歯、ポリライン切替) と対称軸交点アンカー配置
  - 円周方向バックラッシと法線方向カーフ (ビーム径切代) 補正の分離設計
- 機械要素・カスタム形状・既存図形連携
  - 標準軸穴 (丸穴・Dカット・JIS B 1301 キー溝)、パラメトリック肉抜き穴 (丸穴・スポーク窓)
  - 選択円オブジェクトからのピッチ円逆算・色別プリセット適用・輪列ツリー自動構築
  - 「大円 + 小図形」グループからの軸穴/肉抜き抽出および外部 `.ai` テンプレート注入
  - 外周・軸穴・肉抜き穴の複合パス (`CompoundPathItem`) 一体化と、歯の個別オープン出力モード
- CAD / CAM 出力・管理機能
  - 用途別・段別レイヤー階層 (`T1_1`, `T1_LockPlate`, `T1_Carrier`, `T1_dwg` 等)
  - CAD / CAM 線種スタイルプリセット (レーザー加工・JIS機械製図・CNC/3Dプリント・カスタム)
  - JIS B 0003 略画法スケルトン、中心ガイド寸法制御 (固定値 `mm` / 相対値 `%`)、諸元ラベル刻印
  - CSV / TSV による輪列バッチ入出力、JSON 設定プロファイルの自動永続化・書き出し/読み込み
  - 7-bit ASCII (Unicode エスケープ) バンドルによる日本語 Illustrator 環境での文字化け防止

## 同梱ファイル

- `GearDrawer.jsx` : メインスクリプト (Illustrator から直接実行)
- `GearDrawer_Tester.jsx` : Illustrator 実機向け自動検証テストランナー

## 使い方

1. Adobe Illustrator を起動し、新規ドキュメントまたは既存ドキュメントを開く (単位はミリメートル推奨)。
2. メニューの `ファイル > スクリプト > その他のスクリプト...` を選択する。
3. `GearDrawer.jsx` を選択して実行する。
4. ダイアログの `1. 輪列モデリング & 描画` タブで歯車・機構を追加するか、選択円から輪列を構築する。
5. バックラッシやカーフ幅など加工環境に応じたパラメータは `2. 環境設定 & 既定値管理` タブまたは個別諸元欄で調整し、`歯車を描画` をクリックする。
